# note × Threads 運用 AI社員チーム

ゼロから「note（有料記事）× Threads（集客）× アフィリエイト」で収益化するための、28役割のAI社員チームの設計書です。
リサーチから記事・投稿文の作成まではClaudeが担当し、投稿は人が手動で行います。

> 状態：初版完成（2026-11-10）。未確定はThreadsの絵文字の個数のみ（rules/tone.md）。

## 3. 使い方
- 1本作りたいとき：「記事を1本作って。テーマ：○○（なければ、おまかせ）」
- 毎週：「今週の週次サイクルを始めて」（数値・コメント・今週の実録メモを一緒に送る）
- 分析：「数値を分析して」（スクリーンショットか数値を送る）
- ルール変更：「○○のルールを変えて」。作業の途中でも止められる
- Claudeのプロジェクトで使う場合は、`note-threads-ai-team_全文.md` をプロジェクトのファイルにアップロードし、`note-threads-ai-team_プロジェクト指示.txt` の内容を指示欄に貼る
