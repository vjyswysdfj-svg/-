## 人が必ず担当すること
- 体験・数字・経歴など、本人しか知らない事実の提供と確認（本文執筆は「協働」）
- 有料記事の価格の決定、承認1・承認2での判断
- 画像の最終作成（Claudeは指示書を作る。Canvaでの下書き作成は、人が依頼した場合のみ）
- noteとThreadsへの投稿（手動）、数値とコメントの共有

## 役割が重なりやすい箇所の責任範囲

| 重なりやすい役割 | 責任範囲の切り分け |
|---|---|
| 市場調査 ／ トレンド調査 | 市場調査は**月単位で変わらない前提**（需要のあるジャンル、手数料・規約、読者層）。トレンド調査は**今週の話題**（AIツールの新機能、noteやThreadsで話題のテーマ） |
| 競合調査 ／ 参考記事収集 | 競合調査は**アカウント単位**（発信の軸、価格帯、頻度）。参考記事収集は**記事・投稿単位**（構成、1行目、見出しの型） |
| 企画立案 ／ テーマ選定 | 企画立案は**候補を広く出す**（週4〜6案）。テーマ選定は**今週のnote 2本に絞る** |
| 構成設計 ／ 見出し設計 | 構成設計は**記事全体の流れと各段の役割**（tone.md 2章の9段階）。見出し設計は**見出しの文言**（読み飛ばしても内容がわかるか） |
| タイトル作成 ／ 導入文作成 | タイトルは**一覧に表示される一文**。導入文は**本文の最初の3〜5文**（読み続けるか決まる部分） |
| CTA設計 ／ 有料・無料範囲設計 | 有料・無料範囲設計は**どこで線を引き、有料部分に何を置くか**。CTA設計は**読者にしてほしい行動の文言**（購入、フォロー、マガジン登録、LINE登録） |
| 記事レビュー ／ 事実確認 ／ 引用・権利確認 ／ 表現・校正チェック | 記事レビューは**わかりやすさ・構成・読者の役に立つか**。事実確認は**内容の正しさと出典**。引用・権利確認は**他人の文章・画像・データの扱い**。表現・校正チェックは**NG表現・NG条件・法令リスク・誤字・文体**。4つは独立して判定し、1つでもNGなら差し戻す |
| 表現・校正チェック ／ 投稿管理 | 表現・校正チェックは**原稿（文字）の段階**。投稿管理は**公開直前の画面上の最終確認**（画像の表示、リンク、有料ラインの位置、PR表記） |
| SNS告知文作成 ／ タイトル作成 | タイトルは**note記事の題名**。SNS告知文はThreadsに流す**1行目と本文**（記事の告知と日常の集客投稿の両方） |
| 数値分析 ／ 改善提案 | 数値分析は**何が起きたか**（事実の整理）。改善提案は**次に何をするか**。改善提案は数値分析の結果を根拠にする |
