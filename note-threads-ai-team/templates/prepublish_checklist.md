# 公開直前チェックリスト（承認2）

記事タイトル：
公開予定日時：
確認者：（人）

## A. 内容（承認1で決めたとおりか）
- [ ] タイトルが承認1で決めたものと同じ
- [ ] 【要確認】【出典：○○】などの仮置きが本文に残っていない
- [ ] 本人の体験・数字が、記録やスクリーンショットと一致している（時点と期間が書かれている）
- [ ] 「まだできていないこと」または失敗が1つ以上入っている
- [ ] 出典一覧のリンクが開ける

## B. 表現・法令
- [ ] NG表現8項目（rules/ng_expressions.md）に当たる表現がない
- [ ] 実測でない数字、根拠のない「今だけ」「残りわずか」がない
- [ ] アフィリエイトリンクがある場合、PR表記がリンクより前の見える位置にある
- [ ] 美容・健康の商品で効果効能を断定していない
- [ ] 絵文字は記事全体で合計2個以内（矢印・見出しの目印も含む）

## C. 権利・個人情報
- [ ] 引用部分に出典があり、必要最小限になっている
- [ ] 画像・スクリーンショットに他人の投稿・写真・ロゴが写っていない
- [ ] メールアドレス、本名、住所、勤務先、他人のアカウント名が写っていない

## D. noteの画面上の確認
- [ ] 見出し画像が表示され、文字が切れていない
- [ ] 見出し（大見出し・小見出し）が本文より大きく表示されている（本文と同じ大きさのままになっていない）
- [ ] 本文全体が見出しの大きさ・太字になっていない
- [ ] 中央そろえになっている段落がない
- [ ] 見出しの下などに余分な空行がない。意図しない太字の段落がない
- [ ] タイトルが本文の1行目に入っていない
- [ ] 表・図が正しく表示されている
- [ ] 有料記事の場合：有料ラインの位置が承認1で決めた位置にある
- [ ] 有料記事の場合：価格が承認1で決めた金額になっている
- [ ] 価格・部数・期間などの数字が、本文・よくある質問・見出し画像・Threadsの告知文のすべてで一致している（価格を変えたときは全箇所を直す）
- [ ] 購入者の声を載せる場合：本人の許可があり、アカウント名・個人情報を隠している
- [ ] ハッシュタグが設定されている
- [ ] リンク（マガジン、関連記事、アフィリエイト）がすべて正しく開く
- [ ] プレビューで、スマートフォン表示を確認した

## E. 公開後すぐ
- [ ] マガジン「ゼロからAIとnoteを始めた実録」に追加した（記事下の保存ボタン →マガジンの「追加」）
- [ ] 公開URLと日時、価格を投稿記録（templates/metrics_log.md）に書いた
- [ ] Threadsの告知投稿を投稿した（文面は承認1で確認済み）
