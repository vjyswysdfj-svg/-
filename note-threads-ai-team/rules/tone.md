# トーンと構成のルール（案：一部承認待ち）

## 1. 基本トーン：等身大の実録
| 項目 | ルール |
|---|---|
| 立ち位置 | 「ゼロから挑戦中の本人」。専門家・成功者として振る舞わない |
| 一人称 | 私（変更可） |
| 文体 | 暫定：note はです・ます調／Threads は短文、です・ます調を基本に口語を少し混ぜてよい。**条件付き承認**：現在よく読まれているnote記事で、です・ます調が多いと確認できたら確定する（未確認） |
| 失敗の扱い | 各記事に最低1つ、実際の失敗・未解決の課題を入れる |
| 数字 | 実測値のみ。「いつ時点の」「何日間で」を必ず添える。予測は「目標」「見込み」と明記 |
| 絵文字 | note本文：使わない、使う場合も1記事に1〜2個まで（2026-11-10承認）／Threads：暫定1投稿1個まで。現在よく見られている投稿の絵文字の個数を調べて決める（未確認） |

## 2. noteの実録記事の構成型（参考記事の分析から抽出）
1. **冒頭**：今の結果と数字（良くも悪くも）を先に示す
2. **きっかけ・経緯**：日別、またはフェーズ別のタイムライン
3. **仕組みの全体像**：役割の図や表
4. **工夫したポイント**：3〜5個
5. **失敗・罠**：何が起きて、どう直したか
6. **実績データ表**：指標と数値（実測のみ）
7. **読者が真似できる最小ステップ**：3〜5ステップ
8. **まだできていないこと**：未解決の課題を正直に書く
9. **まとめ・CTA**：次の記事、リスト登録、有料部分への案内

- 文字数の目安（推測）：無料記事は3,000〜6,000字。参考記事は約2,500字と約11,500字（記号・空白を除いた概算）で、幅が大きい。運用しながら数値データで見直す。

## 3. Threads投稿の型
- 1行目に主張か意外性を書く（「Threadsマネタイズ完全攻略ガイド」P56、P72の論点を参考）
- 続けて、理由・具体例・補足を書く
- 実録の数字を入れる場合は、時点を明記する
