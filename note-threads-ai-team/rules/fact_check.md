# 事実確認と引用の基準

## 1. 出典の優先順位
1. 公的機関（消費者庁、金融庁、総務省など）
2. サービス提供元の公式情報（note、Meta（Threads）、楽天、LINE、Anthropicなどの公式ヘルプ・規約・発表）
3. 大手報道機関
4. 専門メディア・調査会社（2次情報。可能であれば1〜2で裏付けを取る）

個人のブログ・SNS・まとめサイトは、単独では根拠にしない。元記事が削除されている、回答者数がわからない調査は、根拠として使わない。

## 2. 判定と確信度

| 判定 | 意味 | 対応 |
|---|---|---|
| 確認済み | 1〜3の出典で裏付けがある | 使う。出典と確認日を記録する |
| 出典が古い | 手数料・規約・料金・仕様など、変わった可能性がある | 最新の情報を探す。見つからなければ承認1で確認 |
| 食い違う | 出典によって内容が違う | 違いを示して承認1で確認 |
| 確認できない | 出典が見つからない | 推測で補わない。削除か言い換えを提案する |

すべての事実に確信度（高・中・低）を付ける。

## 3. 本人の体験・数字
- 本人のメモ、管理画面のスクリーンショット、記録表と一致するものだけを使う。
- 数字には時点（いつの数字か）と期間を添える。
- 本人に確認できていない体験・感想は作らない。

## 4. 変わりやすい情報（使うたびに最新を確認する）
- noteの手数料・規約・機能、Threadsの仕様（文字数、タグ）・規約
- 楽天アフィリエイトの料率・規約、LINE公式アカウントの料金・送信数
- AIツールの料金・機能・提供状況
- 景品表示法・薬機法などの運用

## 5. 引用のルール
- 引用は必要最小限にし、引用部分をかぎかっこや引用ブロックで区別する。
- 出典（著者、タイトル、URL、確認日）を明記する。
- 本文が主、引用が従になるようにする。
- 参考記事の文章の流用・言い換えによる模倣はしない（構成と論点の分析のみ）。
- 他人の投稿・画像のスクリーンショットは使わない。

## 6. 記録
確認した出典は、記事パッケージ（`templates/article_package.md`）の「出典一覧」に記録する。
