# 企画のNG条件

企画立案・テーマ選定・表現チェックは、この線引きで判定する。グレーゾーンは承認3で人に確認する。

## 1. 車種・メーカーの扱い

| OK（企画にしてよい） | NG（企画にしない） |
|---|---|
| 公式情報・公的情報にもとづく注意点（リコール、メーカーが公表している不具合、年式による仕様の違いなど）を、出典付きで紹介する | 主観や噂による評価（「壊れやすい」「買うと後悔する」など） |
| 車種名ではなく、特徴やチェックポイントで注意を促す（例：「走行距離のわりに内装がきれいすぎる車は要確認」） | ランキング形式で特定の車種を下げる企画 |

## 2. 整備・メンテナンスの扱い

| OK（企画にしてよい） | NG（企画にしない） |
|---|---|
| 点検の見方や受け方、交換時期の目安、見積もりの見方 | 軽作業以外の分解・交換作業の手順説明 |
| プロに頼むべき理由の解説 | 「自分でやれば○円浮く」を主な訴求にすること |
| 軽作業のDIY（下の定義を参照） | ― |

### 軽作業の定義
次の3つをすべて満たす作業：
1. 車の取扱説明書に、ユーザーが自分で行う作業として載っている
2. 工具をほとんど使わない（車載工具や手で外せる程度）
3. 失敗しても、走行の安全（ブレーキ、タイヤの取り付け、ステアリング、燃料系、高電圧系）に影響しない

| 軽作業（OK）の例 | 軽作業ではない（NG）の例 |
|---|---|
| ワイパーゴム・ブレードの交換 | タイヤ交換 |
| ウォッシャー液の補充 | ブレーキパッドの交換 |
| エアコンフィルター（グローブボックス裏など）の交換 | オイル交換（ジャッキアップや廃油の処理が必要） |
| タイヤの空気圧・溝のチェック | バッテリー交換 |
| ― | 電装品の配線作業 |

### 軽作業を扱う回のルール
- 「車種によって手順が違うので、取扱説明書も確認してください」の一言を入れる。
- 「不安な場合は店舗へ」の一言を入れる（台本またはキャプション）。

## 3. 保険の扱い
- 一般知識の解説に限る。特定の商品を勧めない、比較しない、商品名を出さない（rules/account_profile.md）。

## 4. カスタムの扱い
- 保安基準に適合する範囲で扱う。適合するかどうかの判断が分かれる内容は、事実確認で公的情報の出典を確認し、確認できなければ企画にしない。
