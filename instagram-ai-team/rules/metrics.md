# 追う指標と記録ルール

目標：フォロワーを増やす（認知拡大）

## 1. 指標

| 指標 | 何がわかるか | 主に関係する担当 |
|---|---|---|
| 再生数・リーチ（うちフォロワー外の割合） | 新しい人に届いているか | テーマ選定、フック作成 |
| 平均視聴時間・視聴維持率 | フックと構成が機能しているか | フック作成、構成設計 |
| 保存数・シェア数 | 役に立つ、または人に教えたい内容か | 企画立案、台本作成 |
| 投稿経由のフォロー数 | フォロワー増に直結したか | CTA設計、テーマ選定 |
| コメント（件数と本文） | 視聴者の疑問と、次の企画のネタ | コメント分析 |
| 総フォロワー数（週ごと） | 全体の推移 | 改善提案 |

※ インサイトで表示される項目名は、アプリの更新で変わることがある。表示が変わった場合は、この表を更新する。

## 2. 記録ルール
- **記録の時点**：投稿から**72時間後**の数値を記録する（投稿によって経過日数が違うと比較が不公平になるため）。
- 72時間後に記録できなかった場合は、「共有時点の数値」と「投稿からの経過日数」を記録し、数値分析で注記する。
- **共有の頻度**：週1回、記録表（templates/metrics_log.md）とコメントをまとめて共有する。
- 共有の方法：記録表の文字入力、またはインサイト画面のスクリーンショット。

## 3. 判断ルール
- 1本ずつの数値の上下だけで結論を出さない。少なくとも4週間（約12本）のデータがたまるまでは、傾向は「仮説」として扱う（判断の目安、確信度：中）。
- 一度に変える要素は1〜2個にする（どの変更が効いたかを判断できるようにするため）。
