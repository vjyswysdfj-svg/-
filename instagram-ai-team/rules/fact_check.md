# 事実確認の基準

## 1. 出典の優先順位
1. 公的機関（国土交通省、警察庁、金融庁、各都道府県など）
2. 業界団体・公的な検査機関
3. メーカーの公式サイト・プレスリリース・取扱説明書
4. 大手報道機関
5. 専門メディア（参考扱い。可能であれば1〜4で裏付けを取る）

個人のブログ・SNS・まとめサイトは、単独では根拠にしない。

## 2. 判定

| 判定 | 意味 | 対応 |
|---|---|---|
| 確認済み | 1〜4の出典で裏付けがある | そのまま使う。出典と確認日を記録する |
| 出典が古い | 法令・制度・価格などで、改正や変更の可能性がある | 最新の情報を探す。見つからなければ承認2 |
| 情報が食い違う | 出典によって内容が違う | 違いを示して承認2 |
| 確認できない | 出典が見つからない | 推測で補わない。削除か言い換えを提案して承認2 |

## 3. 経験談の扱い
- 発信者の経験にもとづく内容（例：「営業していた頃、○○を気にするお客さんが多かった」）は、「経験上」「私が見てきた範囲では」と明示すれば使える。
- 経験談の中で、具体的な数値（割合、金額）を断定しない。

## 4. 変わりやすい情報（必ず最新を確認する）
- 法令・制度（道路交通法、保安基準、車検制度、税制、保険制度）
- 価格・相場・手数料
- リコール情報
- 車種の仕様・グレード・発売時期

## 5. 記録
- 確認した出典は、台本パッケージの「出典一覧」に記録する（タイトル、URL、確認日）。
