# Instagram運用 AI社員チーム（車ジャンル・リール中心）

車ジャンルのInstagramリール運用を、28の役割（AI社員）に分けて進めるための設計書です。
リサーチから台本・キャプションまではClaudeが担当し、素材づくり・編集・投稿は人が担当します。

## 1. 前提（ヒアリング結果）

| 項目 | 決定内容 |
|---|---|
| ジャンル | 車関連 |
| 投稿形式 | リール中心 |
| 自動化する範囲 | リサーチ〜台本・キャプションまで（Claudeが担当） |
| 最優先の成果 | フォロワーを増やす（認知拡大）。集客・売上は将来の目標で、導線は未定 |
| 切り口 | 車選び・購入／維持費・メンテナンス／カスタム・趣味 |
| 発信者の強み | 中古車販売の営業経験、カー用品店での整備経験、損保代理店資格（車関連） |
| トーン | 親しみやすい先輩・解説系 |
| 出演形式 | 顔出しなし。AI音声＋テロップ |
| 投稿頻度 | 週3本 |
| 数値の共有 | 週1回まとめて共有 |
| 承認 | 5つの承認ポイントすべてで止まる（`rules/approvals.md`） |

## 2. 使い方

### 毎週の運用（基本）
1. 週1回、先週の3本分のインサイト（スクリーンショット可）と主なコメントを貼り付けて、次のように依頼する：
   > 今週の週次サイクルを始めて
2. Claudeが分析・改善提案・企画3本を出すので、**承認1**（企画の承認）をする。
3. Claudeが3本分の台本パッケージ（台本、テロップ原稿、AI音声原稿、カットリスト、キャプション）を作る。
   途中の**承認2・3**（事実確認、表現の確認）に答える。
4. **承認4**（最終確認）をしたら、人が素材集め・編集・投稿をする。

### 1本だけ作りたいとき
> リールを1本作って。テーマ：○○

Claudeは必要な情報（テーマ、狙い、手持ちの素材など）を確認してから、`workflow.md` の「単発フロー」で進めます。

### Claudeに読み込ませる方法
- Claudeのプロジェクト機能を使う場合：このフォルダのファイルを、プロジェクトのナレッジにアップロードする。
- スキルとして使う場合：`SKILL.md` を含むこのフォルダをスキルとして登録する。

## 3. ファイル構成

```
instagram-ai-team/
├── README.md        … このファイル（全体像と使い方）
├── SKILL.md         … Claudeにスキルとして読み込ませる用の指示書
├── workflow.md      … 週次フロー、単発フロー、承認ポイント、引き継ぎの流れ
├── team/            … 28役割の定義（目的、入力、手順、出力、完了条件、引き継ぎ）
│   ├── 00_roster.md       … 28役割の一覧と担当区分（Claude／人）
│   ├── 01_research.md     … リサーチ部（5役割）
│   ├── 02_planning.md     … 企画部（3役割）
│   ├── 03_writing.md      … 制作・執筆部（5役割）
│   ├── 04_review.md       … 審査部（3役割）
│   ├── 05_production.md   … 素材・編集部（6役割：人が担当）
│   ├── 06_publishing.md   … 品質・投稿部（2役割）
│   ├── 07_analytics.md    … 分析部（3役割）
│   └── 08_management.md   … 進行管理（1役割）
├── rules/           … 運用ルール（更新はClaudeが提案し、人が承認する）
│   ├── account_profile.md … アカウントの前提と、発信の3本柱
│   ├── tone.md            … トーンと話し方、AI音声・テロップのルール
│   ├── ng_expressions.md  … 使ってはいけない表現（9項目）
│   ├── ng_planning.md     … 企画のNG条件と軽作業の定義
│   ├── metrics.md         … 追う指標と記録ルール
│   ├── approvals.md       … 承認ポイント（5か所）
│   └── fact_check.md      … 事実確認の基準
├── templates/       … 出力の型
│   ├── weekly_plan.md     … 週次の企画書
│   ├── script_package.md  … 台本パッケージ（1本分）
│   ├── weekly_report.md   … 週次の分析レポート
│   └── metrics_log.md     … 数値の記録表
└── CHANGELOG.md     … ルールの変更履歴
```

## 4. ルールを更新するには
- 「NG表現に○○を追加して」のように依頼すると、Claudeが変更案を出し、承認後に該当ファイルと `CHANGELOG.md` を更新します（承認5）。
- 収益化の導線が決まったら、`rules/account_profile.md`、`team/03_writing.md`（CTA設計）、`rules/metrics.md` を見直します。
