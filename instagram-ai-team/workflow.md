# ワークフロー

## 1. 週次フロー（週3本）

```
【週1回：人がデータを共有】
  先週3本の数値（72時間後）＋コメント
        │
        ▼
[分析] 26 数値分析 ─┐
       25 コメント分析 ┴→ 27 改善提案 → 5 視聴者分析（月1回更新）
        │
        ▼
[リサーチ] 4 トレンド調査（毎週）
           1 市場調査／2 競合調査／3 投稿収集（月1回、または素材の共有があったとき）
        │
        ▼
[企画] 6 企画立案（6〜10案）→ 7 テーマ選定（3本）
        │
   ★承認1：今週の企画3本を承認
        │
        ▼
[執筆] 8 構成設計 → 9 フック作成 → 10 台本作成
        → 11 タイトル作成／12 CTA設計 → 13 キャプション作成
        │
        ▼
[審査] 14 台本レビュー ／ 15 事実確認 ／ 16 表現チェック（3つを独立に判定）
        │   NGなら該当の担当へ差し戻し
   ★承認2：出典が見つからない・情報が食い違う箇所の判断
   ★承認3：グレーゾーンの表現の判断
        │
        ▼
   ★承認4：台本パッケージ3本の最終確認
        │
        ▼
[人] 17〜22 素材収集・画像生成・図解・字幕・音声・編集
        → 23 品質確認 → 24 投稿管理（週3本を投稿し、72時間後の数値を記録）
        │
        └──→ 次の週の分析へ

※ 28 進行管理が全体を管理し、毎回の作業の最後に進捗表を出す
※ ★承認5：ルールの変更が必要になったときは、どの段階でも止まって確認する
```

## 2. 単発フロー（「リールを1本作って」と依頼されたとき）

1. **進行管理**が、次の情報を確認する（不足していれば質問する。1回に1問）
   - テーマ（決まっていなければ、企画立案から始める）
   - どの柱か（車選び・購入／維持費・メンテナンス／カスタム・趣味）
   - 手持ちの素材（撮影できる車、映像、写真）
   - 投稿予定日
2. テーマが未定の場合：企画立案 → テーマ選定 → **承認1**
3. 構成設計 → フック作成 → 台本作成 → タイトル作成・CTA設計 → キャプション作成
4. 台本レビュー・事実確認・表現チェック → 必要に応じて**承認2・3**
5. **承認4** → 人へ引き渡す

## 3. 担当間の引き継ぎ

| 渡す担当 | 受け取る担当 | 渡すもの |
|---|---|---|
| 市場調査・トレンド調査 | 企画立案 | ネタ一覧（出典・日付付き） |
| 競合調査・投稿収集 | 企画立案・フック作成・構成設計 | 差別化のポイント、型のカード |
| 視聴者分析 | 企画立案・フック作成・CTA設計 | 視聴者像のカード |
| 企画立案 | テーマ選定 | 候補6〜10案 |
| テーマ選定 | 構成設計 | 承認済みのテーマ3本 |
| 構成設計 | フック作成・台本作成 | 秒単位の構成表 |
| フック作成 | 台本作成 | 推奨フック |
| 台本作成 | タイトル作成・CTA設計・審査部 | 台本パッケージ（音声・テロップ・カット・出典） |
| CTA設計 | 台本作成・キャプション作成 | CTAの文言 |
| キャプション作成 | 審査部 | キャプション・ハッシュタグ |
| 審査部 | 進行管理 | 判定結果（OK／差し戻し／要承認） |
| 進行管理 | 人（素材・編集部） | 承認済みの台本パッケージ |
| 投稿管理（人） | 数値分析・コメント分析 | 記録表、コメント |
| 改善提案 | 企画立案（次の週） | 次の週に試すこと1〜2個 |

## 4. 週のスケジュール例

| 曜日 | 作業 | 担当 |
|---|---|---|
| 日 | 数値とコメントの共有 → 分析 → 企画 → 承認1 → 台本3本 → 承認2〜4 | 人＋Claude |
| 月〜火 | 1本目の素材集め・編集 → 火曜に投稿 | 人 |
| 水〜木 | 2本目 → 木曜に投稿 | 人 |
| 金〜土 | 3本目 → 土曜に投稿 | 人 |

投稿の曜日と時刻は初期値です。数値を見て調整します。
